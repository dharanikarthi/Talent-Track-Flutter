# TalentTrack (Flutter)

Light-theme mobile app to record/upload standardized athletic tests, analyze with on-device MediaPipe/TFLite or server fallback (FastAPI + OpenCV/MediaPipe), and gamify progress with coins, XP, and 100 badges.

- Frontend: Flutter (stable), null-safety, Riverpod.
- On-device ML: MediaPipe/TFLite preferred; backend fallback available.
- CI/CD: GitHub Actions for analyze/test on develop and APK builds on main/tags.

See docs/architecture.md, docs/api.md, and docs/runbook.md for details.
